## ⚡ Funksjoner

- Adaptiv vanskelighetsgrad — justeres automatisk etter svarene dine
- XP og streak — lagres mellom besøk (localStorage)
- Shufflede svaralternativer — aldri samme rekkefølge to ganger
- Lydopplaster — last opp NotebookLM-lydfil direkte i appen
- Videospiller — med hastighetskontroll og 15s-hopp
- Torpedospillet — skriv koordinater (f.eks. B4) for å skyte mot AI
